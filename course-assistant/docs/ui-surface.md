# 课程知识问答表面方向

此文件仅供开发与评审，不进入浏览器页面。视觉权威来自父项目 `../../DESIGN.md` 的使用端，以及本子项目 `../DESIGN.md`；最终实现以 `tutor/templates/tutor/index.html`、`tutor/static/tutor/app.css` 和 `app.js` 为准。

## THESIS

Operate 模式：学生提出一个课程知识问题，读到有依据的回答，并能展开 PDF 原文核对。界面围绕这条动作线组织信息。

## OWN-WORLD

继承“安静的深色对话工作台”：炭黑画布、石墨侧栏、低对比边界、稀少柔蓝、无框助教正文。独立 Django 子项目仅扩展课程知识问答，不更换父项目的视觉世界，不引入图像。

## STORY

先检查知识库并显示实际文档与计数，再输入或填入示例问题；提问后读回答，按需展开文件、页码和原文摘录。`llm`、`retrieval_only`、`no_match` 保持各自真实含义；失败保留输入，本页记录可清空。未建立索引时说明下一步。

## FIRST VIEWPORT

桌面左侧 280px 课程与知识库侧栏，右侧 64px 页眉、短问题“从哪个知识点开始？”和底部宽输入器；状态与示例留在左栏。820px 以下改成自然滚动的顶部知识区，520px 以下收紧为单列主体。回答之后才出现按回复折叠的来源依据。

## FORM

这是精确、范围窄的第一条需求：以 Python / Django / SQLite / LangChain / FAISS 实现课程知识问答，并返回 PDF 文件、页码与原文摘录。既有视觉世界已经成立，表面直接由需求塑形；没有设计方向竞赛，seed 阶段不适用。

## FINISH

独立收尾评审的限定复核已完成，结论为 pass，交付处置为 ship；完成状态、无 JavaScript 失败输入保留、无 JavaScript 虚假控件三项发现均为 resolved。最终桌面（1440×960）与手机（390px 宽全页）截图已在最后修复后重采，对应当前代码的真实队列检索及来源引用；30 项测试再次通过，原生提交失败后的输入保留已手动验证。本地已建立 `BAAI/bge-small-zh-v1.5` 索引（15 页、33 个片段）。验证覆盖本地检索、界面、响应式和交互状态；缺少 API Key，真实外部大模型尚未测试。
