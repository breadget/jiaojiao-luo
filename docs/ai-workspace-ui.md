# 统一 AI 智能体对话

## THESIS

首页“询问 AI 智能体”进入 `/ai` 后，课程知识与工作流融合为一个聊天框、一段会话历史和一套模型设置。不再显示课程/工作流模式标签。`/course` 打开相同的统一对话；首页保留创建端，机器人入口继续隐藏。

## OWN-WORLD

这是现有使用端的窄范围扩展，继承 `DESIGN.md` 的炭黑画布、石墨侧栏、冷灰边界、Geist 字体与柔蓝行动点。共享顶栏保留返回和唯一 `h1`，使用端继承已有导航、输入、设置和执行证据。不新增图片资产或视觉世界。

## STORY

进入统一对话 → 输入课程问题或任务 → 智能体检索课程原文 → 同一模型直接回答并提供可展开的文件名、页码和原文，或在用户当前明确要求执行任务时调用所选工作流。知识库按钮仅展示文档清单，不打开第二个聊天界面。选择工具不执行任务，也不重置会话。

模型服务、API Key、模型与推理强度复用现有设置。Django 的受 CSRF 保护 `/api/retrieve/` 只检索真实 FAISS 原文，主站以独立服务会话连接固定 loopback 地址；浏览器密钥不传给 Django。课程内容作为不可信参考资料，不能授权工具。工作流工具无参数，固定绑定服务器当前发布版本与原始用户请求，保留已有图约束、执行防重、数据库签名续接和错误处理。

## FIRST VIEWPORT

共享顶栏高约 64px，下面是一张填满剩余动态视口的聊天工作台。桌面保留侧栏；手机沿用使用端收起导航。底部输入器直接输入课程问题或任务。来源展示在对应回答下，未展开时只呈现简短编号、文件名及页码。设置明确说明两种能力共用同一组模型。

## FORM

未选择工作流也可新建会话、提问课程知识或普通问题；附件、Python 和本机执行沿用既有装载与连接要求。统一会话使用独立稳定分区，工作流选择不改变历史；旧工作流会话保留原协议。回复来源与实际模型保存为白名单元数据，刷新及丢失 HTTP 回复恢复后仍可查看；模型 Key 不写会话和运行台账。

缺少模型密钥时实际能力标为原文检索，显示已找到的来源，不伪装成模型回答或工作流执行。模型调用失败保留真实失败状态，不降级为成功模拟。纯知识回答记录不伪造工作流步骤。Enter 发送、Shift+Enter 换行和中文输入法组合处理继承现有输入器。

## FINISH

2026-10-14 独立最终评审结论为 `ship`，无未解决 P1/P2。桌面与手机完成一次布局审查和一轮针对性确认：未装载工作流可检索课程原文、来源编号可展开、刷新恢复同一记录、设置仅一组模型。未装载工具的文件生成要求保留输入并明确提示。

最终主站回归共 677 项，675 通过，2 项既有环境相关跳过；37 项 Django 测试通过。完整类型、lint、构建与差异检查通过。模型协议、同一套配置传递、无密钥检索、真实失败、引用、防重、权限、历史恢复和多轮数据库限制以隔离响应及真实 SQLite 验证。

统一检索预算 8 秒，任务判断模型预算 30 秒，后续模型或单次 n8n 请求预算 45 秒；数据库每次 HTTP 内的模型纠错共享 45 秒绝对截止时间，签名续接保留原生命周期。普通新问题不会沿用上题课程检索词，明确追问仍结合历史。

实际预览用真实中文向量模型从 15 页、33 片段的 PDF 返回 4 条原文，未配置聊天密钥时没有生成模型回答或执行工作流。外部供应商生成与真实业务工作流未作为本次现场验收结果；它们共用既有模型设置，受相同错误和执行约束。发布后核对记录保存在本地 `.impeccable/review/unified-chat/`。
