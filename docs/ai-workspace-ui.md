# 统一 AI 智能体工作台

## THESIS

首页将工作流使用与课程助教合为“询问 AI 智能体”。用户进入 `/ai`，在同一工作台切换“课程知识 / 工作流”。首页仅显示“创建工作流端”和“询问 AI 智能体”两个入口；机器人入口暂时隐藏，`/robot` 页面保留。`/course` 作为兼容入口打开课程知识模式。

## OWN-WORLD

这是现有使用端的界面扩展，继承根目录 `DESIGN.md` 的炭黑画布、石墨侧栏、冷灰细边界、Geist 字体与稀少柔蓝行动点。共享顶栏负责返回、标题和模式选择；两种内容在相同材料下保留各自导航与操作。门厅、创建端和机器人端继续使用既有设计。没有新增视觉世界，也没有图片资产需求。

## STORY

进入首页 → 询问 AI 智能体 → 默认课程知识 → 输入问题 → 阅读回答并展开原文依据；或切换工作流 → 新建或打开对话 → 按既有流程装载工作流、发送要求和查看执行证据。两种模式使用原生 React 组件嵌入，不使用 iframe。

课程浏览器请求同源 `/api/course/status` 与 `/api/course/ask`，由主站连接本机 Django 课程服务；PDF、向量检索和模型调用仍由课程服务负责。状态与回答分别按实际配置、`llm / retrieval_only / no_match` 呈现，来源保留文件名、页码与可展开原文。工作流继续显示既有真实模型、n8n、模拟回复及执行记录，模式切换本身不执行外部动作。

## FIRST VIEWPORT

工作台占满动态视口。共享顶栏桌面高约 64px，640px 以下分两行高约 104px：返回与标题在第一行，两个模式标签在第二行。内容填满剩余高度，滚动由各内容区域承担。

桌面两种模式的默认侧栏均为 280px；课程模式显示新问题与课程文档清单，工作流模式显示聊天导航。课程侧栏在中等宽度缩为 220px，640px 以下收束为新问题操作，文档清单从标题栏“知识库”展开。工作流沿用自身移动端导航与侧栏收起行为。底部输入器保持宽、清楚且可直接输入，课程来源只在回答后出现。

## FORM

窄范围扩展；direction seed 不适用。共享顶栏的两个按钮使用 `tablist / tab / tabpanel` 与关联标识；当前标签进入 Tab 顺序，左右方向键、Home、End 切换并移动焦点。键盘焦点可见，标签与首页操作至少 44px 高。

两个面板始终挂载，未选面板使用 `hidden` 隐藏，因此切换保留课程草稿、当前问答、已展开来源，以及工作流草稿和当前会话状态；这不代表刷新页面后的课程历史持久化。嵌入模式移除重复品牌与返回入口，公共标题保留唯一 `h1`，内容标题降为 `h2`。课程输入支持 Enter 发送、Shift + Enter 换行，并避开中文输入法组合中的 Enter；加载、失败、重试、知识库未就绪与无匹配结果均显示文字状态。
