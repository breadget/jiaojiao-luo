# 电脑上的 SQLite 数据库

工作流可以读取你电脑上的 `.db`、`.sqlite` 或 `.sqlite3` 文件。线上
`https://urtoris.cn` 通过浏览器连接本机助手，数据库文件留在你的电脑上。
助手只提供表结构和只读查询；AI 使用的表结构、查询结果会发送给你选择的模型。

## 启动并连接

在存有数据库的电脑上安装 Node.js 22.13 或更高版本，打开本仓库目录：

```bash
npm ci
npm run database:local
```

打开 `http://127.0.0.1:3022/connect`，点击“打开工作台并连接”。连接助手
保持运行时，网页才能读取这台电脑上的数据库；在终端按 Ctrl+C 可停止。
如果浏览器询问是否允许网站访问本地网络，请允许 `urtoris.cn` 访问本机助手。
本机开发网页 `http://localhost:3000` 和 `http://127.0.0.1:3000` 也支持连接。

连接代码只保存在当前浏览器标签页的会话中，不写入工作流或服务器。
手动连接时，在上述本机页面展开“手动连接代码”，粘贴到网页的“连接代码”中。
不要分享连接代码。代码文件保存于 `work/local-database/connection-token`，
删除该文件并重启助手可生成新代码，已有网页需要重新连接。

## 配置工作流

1. 在工作台添加“本机数据库”节点。
2. 填写数据库文件的绝对路径，例如 `/Users/你的名字/Documents/orders.sqlite`。
   macOS 可以点击“选择文件”；其他系统直接填写路径，例如 `C:\Users\你的名字\Documents\orders.db`。
3. 点击“测试连接”，确认表结构已读取。
4. 将数据库连接为 AI Agent 的工具，或使用数据库配置中的“连接到 AI Agent”。
5. 编译预览并发布，然后在使用端选择这个工作流、配置模型并开始对话。

本机数据库工作流目前支持一个 Trigger、一个 AI Agent、一个 Output，
以及模型、可选记忆和数据库工具。每个数据库节点配置自己的文件位置和返回行数。
发布会保存本机执行计划；执行时 AI 可以获取表结构并按问题发起查询，
浏览器将查询转发给本机助手，再把结果交给模型回答。

## 读取范围

- 只支持现有 SQLite 文件；不会创建数据库，也不会把整个文件上传到服务器。
- 仅执行一条 `SELECT` 或只读 `WITH` 查询，禁止写入、连接其他数据库、加载扩展和多语句执行。
- 每次最多返回 500 行，并限制响应大小和查询时长；超出返回范围时会显示截断标记。
- 电脑路径保存在工作流配置和发布版本中；连接代码留在当前浏览器标签页。
- 本机数据库工作流从网页对话执行，Python、Shell 和服务器直接运行接口不执行本机数据库计划。
- 换一台电脑、助手停止或文件移动后，需要重新连接并更新对应文件位置。

助手绑定 `127.0.0.1:3022`，仅接受上述网站和本机开发地址，并要求连接代码。
它与本机 Shell Control Agent 独立，不提供 Shell 命令执行接口。

Node.js 22.13 和 24 已验证。22.13 的 SQLite API 对空结果不提供列名，
查询时为同名列设置不同别名可以保留各列结果。
