## 已确认事项（阻塞项已解除）

1. **本机容器**：采用 Colima，不安装 Docker Desktop。
2. **长任务档位**：只保留 `long`（10 分钟 / 2 GiB / 2 vCPU），暂不增加 30 分钟档。
3. **本地节点定位**：只服务本人，不接线上，不做节点注册或隧道。

## 风险与对策

- **本地隔离弱于线上**：Docker Desktop 里通常没有 AppArmor，只有 seccomp。对策：本地节点按 `requireLsm: false` 跑，并在界面与文档明确标注"本地节点隔离弱于线上"，且只处理你自己的数据。
- **本机休眠/合盖会打断任务**：对策：任务状态落库，重启后如实显示"因节点离线中断"，不假装成功；长任务建议插电不睡眠。
- **长任务占资源**：本地并发上限 1，随时可取消，超限直接拒绝而不是排队堆积。
- **界面回归**：任何界面改动都复用现有流程（设计检测 0 告警 + 五档宽度截图 + 键盘可达性）。

## 追加实施：本机全权限 Shell

用户随后明确要求网页 Agent 可以「什么都能干」。本次将它落为机主专用、
当前 macOS 用户权限的任意 Shell；不是 Python 沙箱，不自动提权为 root，也不接
`urtoris.cn`。决策、运行方式与验收分别见：

- [`ADR-003-local-full-control.md`](../ADR-003-local-full-control.md)
- [`services/local-control/README.md`](../../services/local-control/README.md)
- [`evidence/local-control-review.json`](../evidence/local-control-review.json)

收尾时并发测试暴露出执行器的一个真实缺陷：`error` / `exit` / `close` 是一次性事件，
而执行器在挂监听器之前先等了一次落盘，于是跑得比写盘快的命令（10 路并发里 3 次）
会退出到空监听列表，运行永远停在 `running` 并占住唯一并发位。修法是监听器在第一个
`await` 之前挂上、同一次运行的三次落盘串行执行；另外命令退出后若输出管道被后台进程
继续持有，最多再等 2 秒按退出码定稿。回归见
[`tests/local-control-executor.test.ts`](../../tests/local-control-executor.test.ts)，
端到端真实门禁见 `npm run control:gate`。
